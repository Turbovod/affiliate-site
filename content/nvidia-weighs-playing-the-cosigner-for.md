# Nvidia рассматривает возможность стать поручителем для AI-датацентра Nscale в Западной Виргинии: что это значит для рынка?

Последние новости индустрии сообщают, что Nvidia рассматривает возможность стать финансовым гарантом (поручителем) для крупного проекта компании Nscale по строительству AI-датацентра в штате Западная Виргиния. Для Nvidia это не просто благотворительность. Инвестиции в инфраструктуру — это способ гарантировать, что спрос на чипы H100 и Blackwell останется стабильно высоким. Становясь поручителем, Nvidia фактически снижает риски для банков и кредиторов, что позволяет Nscale быстрее привлекать капитал для масштабного строительства.

Западная Виргиния была выбрана не случайно: штат предлагает относительно дешевую электроэнергию и благоприятные условия для размещения крупных энергетических мощностей, необходимых для охлаждения и питания тысяч серверов.
